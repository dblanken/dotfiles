# Claude Code config

Claude Code config (CLAUDE.md, rules, memory, skills, hooks, settings) is no longer in this repo.
It lives in the private `claude-config` repo, with a `work` profile (Mac) and a `personal` profile (Linux).
Deploy it with `./deploy.sh work|personal` from that repo, in your own terminal; see its `DEPLOY.md`.
`install.sh` and the Makefile do not touch `~/.claude`.
